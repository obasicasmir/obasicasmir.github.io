# Casmir O. Obasi — Academic website

Static academic portfolio for [obasicasmir.github.io](https://obasicasmir.github.io/).

## Structure

- `index.html` — page content and metadata
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and subtle reveal effects
- `assets/favicon.svg` — site icon

The site uses plain HTML, CSS, and JavaScript, so GitHub Pages can publish it directly from the repository root without a build step.

## Local preview

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.
